# Mrudula Joshi — Portfolio

This is a framework-free personal portfolio built with:

- HTML5
- CSS3
- Vanilla JavaScript

## Add your photo

Place your professional LinkedIn photo at:

```text
portfolio/images/profile.jpg
```

The site currently shows a simple initials fallback until the real photo is added. No fake profile photo is included.

## Add your resume

Place your resume PDF at:

```text
portfolio/assets/Mrudula_Joshi_Resume.pdf
```

The “Download Resume” buttons already point to that exact path.

## Personalize the site

Open `index.html` and replace:

- `your-email@example.com`
- `https://linkedin.com/in/your-profile`
- `https://github.com/your-profile`
- Project GitHub and live-demo placeholder links
- Course and certification fields

The course cards are also directly editable in the browser, but edits made there are not saved after refreshing. To keep them permanently, update the matching content in `index.html`.

## Run it locally

Open `index.html` directly in a browser, or serve the folder with any simple local server. No installation or build step is required.
